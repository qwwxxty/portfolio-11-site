# Пасмо — демо-сайт перукарні (Суми)
Чистий HTML/CSS/JS, без збирача. Файли: index.html, styles.css, script.js, assets/.

## Публікація на GitHub Pages
Залити в репозиторій → Settings → Pages → Deploy from branch → main / root.

## Припущення
Бренд, адреса, години, ціни, майстри вигадані. Фото — SVG-заглушки. Форма — Formspree-заглушка (`YOUR_FORM_ID`). og:image потребує PNG/JPG після появи фото. 768 px окремо не знімався.

## Місця з [уточнити]
- Вхід з двору (секція «Адреса»)
- Телефон, Telegram, Instagram, email — заглушки
- Formspree ID у формі
